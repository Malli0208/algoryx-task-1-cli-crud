# Student Management System

A professional command-line Student Management System built with Python and SQLite as part of the Algoryx Python Internship – Task 1.

## Features

- Create student records
- View all students
- Search students
- Update student records
- Delete student records
- SQLite persistent storage
- Input validation
- Exception handling
- Duplicate email prevention
- Modular project architecture
- Menu-driven command-line interface

## Technologies Used

- Python 3
- SQLite
- Python Standard Library
